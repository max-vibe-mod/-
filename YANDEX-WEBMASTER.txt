# Инструкция: Яндекс.Вебмастер для максвайб.рф
# После получения кода замените PASTE_YANDEX_CODE_HERE в index.html

Шаги проверки:
1) https://webmaster.yandex.ru/ → «Добавить сайт» → https://максвайб.рф/
2) Способ «Метатег» → скопируйте content="XXXX"
3) В docs/index.html замените PASTE_YANDEX_CODE_HERE → залейте сайт → «Проверить»

Индексация:
4) Индексирование → Файлы Sitemap → https://максвайб.рф/sitemap.xml
5) Переобход страниц:
   https://максвайб.рф/
   https://максвайб.рф/maks-mod.html
   https://максвайб.рф/mod-na-maks.html
   https://максвайб.рф/whitemax.html
   https://максвайб.рф/safemax.html
   https://максвайб.рф/dorofo.html
6) Важные страницы → главная + maks-mod.html (запрос «макс мод»)

РЕГИОНАЛЬНОСТЬ (обязательно для Яндекса):
7) Представление → Региональность / Регион сайта
   → выберите «Россия» (или «Москва», если просит город)
   → сохраните
8) Если есть пункт «Ориентация на регион» — Россия / СНГ

Дополнительно:
9) Яндекс Метрика — счётчик на сайт (ускоряет данные по запросам)
10) Индексирование → История обхода — следите, что страницы «макс мод» в индексе
11) Поиск → Поисковые запросы — смотрите «макс мод», «мод на макс»

Цель: регион Россия + sitemap + важные URL = выше выдача по «макс мод» в РФ.
